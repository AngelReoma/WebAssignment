Explaning my HTML Tags

  • <!DOCTYPE html>: declaration defines that this document is an HTML5 document
  • <html>: the root element of an HTML page
  • <head>: element contains meta information about HTML page
  • <title>: element specifies a title for HTML page
  • <body>: element defines the document's body and container for all visible contents
  • <h1-5>: element defines heading
  • <p>: element defines a paragraph
  • <a>: element creates hyperlinks
  • <img>: element that embed an image in a web page
  • <tables>: element used to organise data into tables
  • <ul>: element that creates unordered list
